# 📌 Project Title & Overview

## Title:
🎓 Student Performance Analysis using Machine Learning & Interactive Visualization

## Summary:
An end-to-end Data Science and Machine Learning project that analyzes student academic performance using statistical analysis, predictive modeling, clustering, and interactive 3D visualizations.

The project helps identify patterns affecting student grades and provides visual insights into study habits, attendance, parent education, and overall academic outcomes.

---

# 🎯 Core Objectives

## 📊 Academic Performance Analysis
Analyze student-related factors influencing academic success.

## 🔍 Pattern Discovery
Identify relationships between:
- Study time
- Absences
- Parent education
- Guardian support
- Student grades

## 🤖 Machine Learning Development
Build multiple ML models for:
- Classification
- Regression
- Clustering

## 🌐 Interactive Visualization
Create interactive 3D visualizations for better data exploration and understanding.

---

# 📊 Dataset & Column Descriptions

The dataset contains academic, social, and demographic information of students.

## Important Features

### G1
First period grade.

### G2
Second period grade.

### G3
Final grade (Target variable).

### studytime
Weekly study time of students.

### absences
Number of school absences.

### Medu
Mother’s education level.

### Fedu
Father’s education level.

### guardian
Student’s guardian type.

### Mjob
Mother’s job category.

### sex
Gender of the student.
